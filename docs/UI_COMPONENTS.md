# UI 컴포넌트 구성

> 로또 운 타임머신은 **한 화면짜리 서비스**입니다. 랜딩 페이지나 로그인 없이, 접속하면 바로 번호를 고르고 결과를 봅니다.
> 기술: React 19 + Vite · 서버 없음 (모든 계산은 브라우저에서 실행)

## 1. 화면 흐름

```
 ┌──────────────┐   번호 6개 선택   ┌──────────────┐   2.6초 연출   ┌──────────────┐
 │   pick       │ ───────────────▶ │   drawing    │ ────────────▶ │   result     │
 │ 번호 고르기   │  "나의 운 확인하기" │ 뽑기 기계 회전 │                │ 결과 + 이펙트 │
 └──────────────┘                  └──────────────┘                └──────┬───────┘
        ▲                                                                 │
        └─────────────────── 번호를 바꾸면 결과를 지우고 처음 단계로 ─────────┘
```

## 2. 화면 배치 (위에서 아래로)

| 순서 | 영역 | 컴포넌트 | 보이는 시점 |
|---|---|---|---|
| 1 | 제목, 소개 문구, 소리 켜기/끄기 | `App` 안의 header | 항상 |
| 2 | **화면 중앙의 뽑기 기계** | `GachaMachine` | 항상 |
| 3 | 번호 6칸 + 보조 버튼 + "나의 운 확인하기" | `NumberSlots` | 항상 |
| 4 | 총 당첨 횟수·금액 (크게) | `ResultSummary` | 결과 단계 |
| 5 | 회차별 기록 리스트 | `RoundList` | 결과 단계 |
| 6 | 안내 문구 (가정, 데이터 출처) | `App` 안의 footer | 항상 |
| 겹침 | 1~45 번호판 | `NumberPicker` | 동그라미를 눌렀을 때 |
| 겹침 | 폭죽 / 먹구름 비 | `Confetti` | 결과가 나온 순간 |

## 3. 컴포넌트 트리

```
App                          상태 관리, 단계 전환, 효과음 호출
├── GachaMachine             뽑기 기계 애니메이션 + 상태 문구 + 결과 공
├── NumberSlots              동그라미 6칸
│   └── Ball                 로또 공 (공용)
├── ResultSummary            결과 요약 (숫자 카운트업, 유머 문구)
├── RoundList                회차별 당첨 기록 (20개씩 더 보기)
│   └── Ball
├── NumberPicker             1~45 번호판 (모달)
│   └── Ball
└── Confetti                 결과 이펙트 (canvas)
```

## 4. 컴포넌트 상세

### `App` · [src/App.jsx](../src/App.jsx)
화면 전체를 관리하는 최상위 컴포넌트입니다.

| 상태 | 의미 |
|---|---|
| `numbers` | 고른 번호 6칸 (빈칸은 `null`) |
| `editing` | 번호판이 열린 칸의 위치 (닫혀 있으면 `null`) |
| `phase` | 현재 단계: `pick` → `drawing` → `result` |
| `result` | 계산 결과 (`analyze()`의 반환값) |
| `fxKey` | 결과 이펙트를 다시 실행하기 위한 번호 |
| `muted` | 소리 끄기 여부 |

- "나의 운 확인하기"를 누르면 결과를 **즉시 계산**해 두고, 연출 시간(2.6초)이 지난 뒤 공개합니다.
- 결과가 나오면 등수에 따라 화면을 흔들고(1등이 가장 세게, 낙첨은 화면이 잿빛으로) 결과 영역으로 스크롤합니다.
- 번호를 바꾸면 이전 결과를 지웁니다. 화면의 결과와 고른 번호가 항상 일치하게 하기 위해서입니다.

### `GachaMachine` · [src/components/GachaMachine.jsx](../src/components/GachaMachine.jsx)
화면 중앙의 뽑기 기계입니다. 이 서비스의 시각적 중심입니다.

| props | 설명 |
|---|---|
| `phase` | 단계에 따라 애니메이션이 바뀝니다 |
| `ready` | 번호 6개를 다 골랐는지 (문구 변경용) |
| `firstRound`, `latestRound` | 추첨 중 회차 번호를 굴릴 범위 |
| `bestRank` | 결과 공에 표시할 최고 등수 |

| 단계 | 모습 |
|---|---|
| 대기 | 돔 안의 공 12개가 살랑살랑 움직임. "번호 6개를 골라주세요" / "준비 완료! 돌려볼까요?" |
| 추첨 중 | 돔이 떨리고 공이 마구 뒤섞임. "294회 → 1244회 추첨 중…"으로 회차 번호가 빠르게 넘어감 |
| 결과 | 기계에서 큰 공이 튀어나옴. 1등이면 금빛으로 빛나며 흔들리고, 낙첨이면 "꽝" 공이 힘없이 기울어짐 |

### `NumberSlots` · [src/components/NumberSlots.jsx](../src/components/NumberSlots.jsx)
번호 6칸입니다. **키보드로 입력하지 않고, 동그라미를 눌러 고릅니다.**

| props | 설명 |
|---|---|
| `numbers` | 6칸의 현재 번호 |
| `onSlotClick(index)` | 칸을 누르면 그 칸의 번호판을 엶 |
| `disabled` | 추첨 중에는 누를 수 없음 |

### `NumberPicker` · [src/components/NumberPicker.jsx](../src/components/NumberPicker.jsx)
1~45 번호판 모달입니다. 모바일에서는 아래에서 올라오고, 넓은 화면에서는 가운데에 뜹니다.

| props | 설명 |
|---|---|
| `slot` | 몇 번째 칸을 고르는 중인지 |
| `current` | 그 칸의 현재 번호 (강조 표시) |
| `taken` | 다른 칸에서 이미 고른 번호 (흐리게, 선택 불가) |
| `onPick(n)` | 번호 선택. **다음 빈칸으로 자동 이동**하고, 다 채우면 닫힘 |
| `onClear` | 이 칸 비우기 |
| `onClose` | 닫기 (바깥 클릭, Esc 키도 가능) |

### `Ball` · [src/components/Ball.jsx](../src/components/Ball.jsx)
로또 공 하나입니다. 모든 화면에서 같이 씁니다.
실제 로또 공과 같은 색 규칙을 따릅니다: 1~10 노랑 · 11~20 파랑 · 21~30 빨강 · 31~40 회색 · 41~45 초록

| props | 설명 |
|---|---|
| `n` | 번호 (없으면 빈 동그라미) |
| `size` | `sm`(목록) / `md`(번호판) / `lg`(선택 칸, 화면 폭에 맞춰 줄어듦) |
| `dim` | 흐리게 (목록에서 내 번호가 아닌 공, 이미 고른 번호) |
| `bonus` | 보너스 번호 표시 (점선 테두리) |

### `ResultSummary` · [src/components/ResultSummary.jsx](../src/components/ResultSummary.jsx)
결과의 핵심을 **가장 크게** 보여줍니다.

| 표시 항목 | 내용 |
|---|---|
| 제목 | 최고 등수에 맞는 유머 문구 (예: 1등이면 "전생에 나라를 구하셨군요") |
| 총 당첨 | 당첨 횟수. 0부터 올라가는 카운트업 연출 |
| 받았을 돈 | 가상 당첨금 합계. 카운트업 연출 |
| 등수별 칩 | 1~5등 각각 몇 번인지 |
| 손익 | 총 구매액(주 수 × 1,000원)과 순이익. 이익은 초록, 손해는 빨강 |
| 한마디 | 손익에 맞는 유머 문구. 손해면 "치킨 약 N마리"로 환산 |

### `RoundList` · [src/components/RoundList.jsx](../src/components/RoundList.jsx)
당첨된 회차를 **최신순**으로 보여줍니다. 처음 20개를 보여주고 "더 보기"로 20개씩 늘립니다.

| 한 줄에 보이는 것 | 설명 |
|---|---|
| 회차, 추첨일, 등수 배지 | 등수마다 왼쪽 테두리 색이 다름 |
| 당첨번호 6개 + 보너스 | **내 번호와 맞은 공만 진하게**, 나머지는 흐리게 |
| 가상 당첨금 | 내가 받았을 금액 |
| 계산 근거 | "실제 당첨자 22명 + 나 = 23명이 나눔" / "1등이 없던 회차! 이월금을 혼자 독차지" / "고정 금액" |

계산 근거를 한 줄씩 보여주는 이유: 실제 당첨금과 금액이 다르게 나오므로, 사용자가 "왜 이 금액인지" 바로 알 수 있게 하기 위해서입니다.

### `Confetti` · [src/components/Confetti.jsx](../src/components/Confetti.jsx)
결과가 나온 순간의 과장된 이펙트입니다. `<canvas>`에 직접 그립니다.

| 결과 | 이펙트 |
|---|---|
| 1등 | 색종이 500개가 화면 중앙에서 폭발 |
| 2등 → 5등 | 등수가 낮을수록 색종이가 줄어듦 (320 → 70개) |
| 낙첨 | 회색 빗줄기가 위에서 쏟아짐 |

동작 줄이기 설정(`prefers-reduced-motion`)을 켠 사용자에게는 이펙트를 보여주지 않습니다.

## 5. 컴포넌트가 아닌 모듈

| 파일 | 역할 |
|---|---|
| [src/lib/lotto.js](../src/lib/lotto.js) | 검증된 로또 데이터 연결 |
| [src/lib/prize.js](../src/lib/prize.js) | 등수 판정, 가상 당첨금 계산 ([계산 규칙](DATA_VERIFICATION.md#7-가상-당첨금-계산-규칙)) |
| [src/lib/analyze.js](../src/lib/analyze.js) | 전 회차 집계 (당첨 횟수, 총액, 손익) |
| [src/lib/sound.js](../src/lib/sound.js) | 효과음. **음원 파일 없이 Web Audio API로 직접 합성** |
| [src/content/copy.js](../src/content/copy.js) | 유머 문구 모음. 문구에는 숫자를 넣지 않고 숫자는 항상 계산 결과에서 채움 |

### 효과음 설계

| 시점 | 소리 |
|---|---|
| 번호 선택 | 짧게 올라가는 "뿅" |
| 추첨 중 | 공이 부딪히는 "딸깍" 소리가 점점 빨라짐 |
| 1등 | 도-미-솔-도 팡파르 4번 반복 + 반짝이는 소리 |
| 2~5등 | 팡파르 반복 횟수가 줄어듦 |
| 낙첨 | 슬픈 트롬본 "빠-바-바-바아암" |

브라우저 정책상 소리는 사용자가 버튼을 누른 뒤에만 나며, 상단 버튼으로 끌 수 있습니다.

## 6. 반응형

- 좁은 화면(휴대폰)을 기준으로 만들었고, 최대 폭은 720px입니다.
- 번호 6칸과 번호판의 공 크기는 화면 폭에 맞춰 줄어들어 한 줄에 들어갑니다.
- 결과의 큰 숫자 두 칸은 480px 이하에서 위아래로 쌓입니다.
